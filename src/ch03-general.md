# 3.3. Общие регистры

Общие регистры расположены в диапазоне смещений `0x000`–`0x01C`. Они делятся
на две группы: регистры данных и управления (`RTCDR`, `RTCMR`, `RTCLR`,
`RTCCR`) и регистры прерывания (`RTCIMSC`, `RTCRIS`, `RTCMIS`, `RTCICR`).

## Перечень

| Регистр | Смещение | Тип | Назначение |
|---------|----------|-----|------------|
| `RTCDR` | `0x000` | RO | Текущее значение счётчика |
| `RTCMR` | `0x004` | RW | Значение совпадения |
| `RTCLR` | `0x008` | RW | Загрузка счётчика |
| `RTCCR` | `0x00C` | RW | Управление счётом |
| `RTCIMSC` | `0x010` | RW | Маска прерывания |
| `RTCRIS` | `0x014` | RO | Сырой статус |
| `RTCMIS` | `0x018` | RO | Маскированный статус |
| `RTCICR` | `0x01C` | WO | Сброс прерывания |

## Связь регистров

```text
        запись                     чтение
   ┌──────────────┐          ┌──────────────┐
   │    RTCLR     │          │    RTCDR     │
   └──────┬───────┘          └──────▲───────┘
          │ загрузка                │ текущее значение
   ┌──────▼───────┐                 │
   │   Счётчик    │─────────────────┘
   └──────┬───────┘
          │ сравнение
   ┌──────▼───────┐
   │    RTCMR     │
   └──────┬───────┘
          │ совпадение
   ┌──────▼───────┐      ┌──────────────┐
   │    RTCRIS    │─AND─▶│    RTCMIS    │──▶ RTCINTR
   └──────▲───────┘      └──────▲───────┘
          │ сброс               │
   ┌──────┴───────┐      ┌──────┴───────┐
   │    RTCICR    │      │   RTCIMSC    │
   └──────────────┘      └──────────────┘
```

## Общие правила

- Значение счётчика всегда доступно через `RTCDR`; для записи используется
  только `RTCLR`.
- Флаг прерывания устанавливается аппаратно и сбрасывается только записью
  в `RTCICR`.
- Маска прерывания не влияет на флаг в `RTCRIS`: она влияет только
  на `RTCMIS` и выход `RTCINTR`.

Далее каждый регистр описан отдельно, с таблицей битовых полей.
