# 3.6. Прерывания

Контроллер формирует одно прерывание — по совпадению значения счётчика
со значением регистра `RTCMR`. Прерывание выводится сигналом `RTCINTR`,
который подключается к контроллеру прерываний системы.

## Путь сигнала

```text
  счётчик ──┬──────────────┐
            │              │
            │        ┌─────▼──────┐
  RTCMR ────┴───────▶│  сравнение │
                     └─────┬──────┘
                           │ совпадение
                     ┌─────▼──────┐
                     │  RTCRIS[0] │◀── сброс: RTCICR[0]
                     └─────┬──────┘
                           │
                     ┌─────▼──────┐
        RTCIMSC[0] ─▶│    AND     │
                     └─────┬──────┘
                           │
                     ┌─────▼──────┐
                     │  RTCMIS[0] │──▶ RTCINTR
                     └────────────┘
```

## Состояния

| `RTCRIS[0]` | `RTCIMSC[0]` | `RTCMIS[0]` | `RTCINTR` | Комментарий |
|-------------|--------------|-------------|-----------|-------------|
| 0 | 0 | 0 | Не активен | События нет, прерывание запрещено |
| 0 | 1 | 0 | Не активен | События нет, прерывание разрешено |
| 1 | 0 | 0 | Не активен | Событие есть, но замаскировано |
| 1 | 1 | 1 | Активен | Событие есть, прерывание выдаётся |

## Программная модель

### Разрешение

```c
*(volatile uint32_t *)(RTC_BASE + 0x010) = 1;   /* RTCIMSC */
```

### Запрещение

```c
*(volatile uint32_t *)(RTC_BASE + 0x010) = 0;
```

### Сброс флага

```c
*(volatile uint32_t *)(RTC_BASE + 0x01C) = 1;   /* RTCICR */
```

Запись единицы в `RTCICR` сбрасывает `RTCRIS`, что автоматически снимает
`RTCMIS` и деактивирует `RTCINTR`.

## Рекомендации по обработке

1. **Проверяйте источник.** Если линия прерывания разделяется с другими
   устройствами, читайте `RTCMIS` и убеждайтесь, что бит `[0]` установлен.
2. **Сбрасывайте флаг до выхода из обработчика.** Иначе прерывание будет
   повторяться бесконечно.
3. **Перепрограммируйте `RTCMR` заранее**, если нужны периодические
   срабатывания: одного совпадения недостаточно для повтора.
4. **Учитывайте задержку синхронизации.** Между записью в `RTCMR`
   и фактическим применением значения проходит до одного такта `CLK1HZ`.

## Периодические прерывания

Контроллер не имеет встроенного счётчика повторов. Чтобы получить
периодическое прерывание, обработчик должен сам записать следующее значение:

```c
void rtc_irq_handler(void)
{
    if (!(*(volatile uint32_t *)(RTC_BASE + 0x018) & 1))
        return;

    *(volatile uint32_t *)(RTC_BASE + 0x01C) = 1;

    /* Следующее срабатывание через 1 секунду */
    *(volatile uint32_t *)(RTC_BASE + 0x004) =
        *(volatile uint32_t *)(RTC_BASE + 0x000) + 1;
}
```

Такой подход даёт точность, ограниченную временем входа в обработчик:
если обработчик задержится больше чем на секунду, срабатывание будет
пропущено.
