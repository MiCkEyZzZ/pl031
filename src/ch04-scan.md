# 4.2. Scan-тестирование

Контроллер спроектирован так, чтобы упростить вставку scan-ячеек
и применение автоматической генерации тестовых воздействий (Automatic Test
Pattern Generation, ATPG) — альтернативного метода производственного
тестирования.

## Выводы scan-тестирования

Выводы организованы с учётом двух тактовых доменов контроллера.

| Сигнал | Домен | Назначение |
|--------|-------|------------|
| `SCANENABLE` | общий | Разрешение scan-режима |
| `SCANINPCLK` | `PCLK` | Вход данных scan-цепочки домена `PCLK` |
| `SCANOUTPCLK` | `PCLK` | Выход данных scan-цепочки домена `PCLK` |
| `SCANINCLK1HZ` | `CLK1HZ` | Вход данных scan-цепочки домена `CLK1HZ` |
| `SCANOUTCLK1HZ` | `CLK1HZ` | Выход данных scan-цепочки домена `CLK1HZ` |

Разделение цепочек по доменам важно: scan-сдвиг выполняется на тактовой
частоте соответствующего домена, и объединение доменов в одну цепочку
потребовало бы дополнительной синхронизации.

## Статус выводов

В текущей ревизии контроллера перечисленные выводы являются
зарезервированными (place holder): они предусмотрены структурой блока,
но не описаны как функциональные. Иными словами, они не участвуют
в штатной работе и не проверяются интеграционными тестовыми векторами
(см. таблицу в разделе 4.6).

## Как это используется

При производственном тестировании сканирующие цепочки позволяют подать
на внутренние триггеры произвольную комбинацию значений и прочитать
результат после одного такта. Это даёт высокое покрытие неисправностей
без функциональных тестов.

Для контроллера RTC scan-тестирование особенно полезно для медленного
домена `CLK1HZ`: функциональная проверка заняла бы секунды на каждый шаг,
а scan-сдвиг выполняется за такты.

## Различие между scan- и интеграционным тестом

| Аспект | Scan-тест | Интеграционный тест |
|--------|-----------|---------------------|
| Доступ | Внутренние триггеры | Регистры через APB |
| Управление | Внешний тест-контроллер | Программное обеспечение |
| Скорость | Такты | Секунды для домена `CLK1HZ` |
| Цель | Обнаружение дефектов изготовления | Проверка соединений блоков |
