# 3.3.4. Регистр управления RTCCR

`RTCCR` — регистр управления, содержащий единственный значащий бит,
который разрешает или запрещает увеличение счётчика.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x00C` |
| Тип | RW |
| Ширина | 1 бит |
| Значение после сброса | `0x00000000` |

## Битовые поля

| Биты | Имя | Тип | Описание |
|------|-----|-----|----------|
| 31:1 | — | — | Зарезервировано, читается как ноль, изменять нельзя |
| 0 | `RTCEN` | RW | 1 — счёт разрешён, 0 — счёт остановлен |

## Описание

Бит `RTCEN` управляет инкрементом счётчика. Когда он равен единице, каждый
фронт `CLK1HZ` увеличивает счётчик. Когда он равен нулю, счётчик сохраняет
текущее значение.

Остальные функции контроллера при остановленном счётчике продолжают
работать: чтение `RTCDR`, запись `RTCLR`, сравнение с `RTCMR` и обработка
прерываний.

## Значение после сброса

После сброса бит равен нулю, то есть счётчик остановлен. Это защищает
систему от отсчёта времени до того, как программное обеспечение загрузит
корректное начальное значение.

## Пример использования

```c
#define RTC_CR      (RTC_BASE + 0x00C)
#define RTC_CR_EN   (1u << 0)

/* Загрузить время и запустить счёт */
*(volatile uint32_t *)(RTC_BASE + 0x008) = start_seconds;
*(volatile uint32_t *)RTC_CR |= RTC_CR_EN;

/* Остановить счёт, сохранив показания */
*(volatile uint32_t *)RTC_CR &= ~RTC_CR_EN;
```

## Замечание

Изменение бита `RTCEN` также проходит через блок синхронизации. Поэтому
между записью и фактической остановкой или запуском счётчика может пройти
до одного такта `CLK1HZ`. Если счётчик нужно остановить точно, следует
учитывать эту задержку.
