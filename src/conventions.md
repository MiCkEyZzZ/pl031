# Обозначения и соглашения

## Типографика

В тексте используются следующие соглашения.

| Оформление | Значение |
|------------|----------|
| `моноширинный` | Имена регистров, сигналов, полей, адреса и значения |
| **Полужирный** | Названия элементов интерфейса и важные термины |
| *Курсив* | Термины, определённые в глоссарии |

Числа записываются в шестнадцатеричном виде с префиксом `0x` (`0x1C`),
в двоичном — с префиксом `0b` (`0b0001`). Отдельные биты обозначаются как
`RTCCR[0]`, диапазоны — как `PADDR[11:2]`.

## Имена сигналов

Сигналы с активным низким уровнем имеют префикс `n`:

- `PRESETn` — сброс шины, активен низким уровнем;
- `nRTCRST` — сброс ядра RTC, активен низким уровнем;
- `nPOR` — сброс по включению питания, активен низким уровнем.

Сигнал без префикса считается активным высоким уровнем (`RTCINTR`).

## Типы доступа к регистрам

| Тип | Значение |
|-----|----------|
| RO | Read-only: только чтение, запись игнорируется |
| WO | Write-only: только запись, чтение не определено |
| RW | Read/write: чтение и запись |
| — | Поле отсутствует |
| DNM | Do Not Modify: зарезервировано, изменять нельзя |

Зарезервированные поля при записи должны сохранять значение, прочитанное
из регистра. Если в описании указано «Read as zero», чтение возвращает нули.

## Сброс и значения по умолчанию

Если не указано иное, значение регистра после сброса равно `0x00000000`.
Регистры `RTCMR` и регистры смещения не сбрасываются сигналом `PRESETn`:
они сохраняют значение при сбросе шины и сбрасываются только сигналом
`nPOR` (см. раздел 2.3.1).

## Диаграммы времени

На временных диаграммах приняты обозначения:

- сплошная линия — достоверный уровень сигнала;
- переход между уровнями — фронт сигнала;
- штриховая линия — момент, когда значение сигнала не важно;
- вертикальные линии отмечают границы тактов `PCLK`.

Диаграммы показывают идеализированное поведение; фактические задержки
зависят от реализации и технологии.

## Термины

Термины «ведущий» и «ведомый» относятся к ролям на шине: ведущий инициирует
обмен, ведомый отвечает на запросы. Контроллер PL031 всегда является ведомым
устройством APB.
