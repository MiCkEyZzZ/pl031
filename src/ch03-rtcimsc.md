# 3.3.5. Регистр маски прерывания RTCIMSC

`RTCIMSC` — регистр чтения/записи, управляющий маскированием прерывания
от контроллера.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x010` |
| Тип | RW |
| Ширина | 1 бит |
| Значение после сброса | `0x00000000` |

## Битовые поля

| Биты | Имя | Тип | Описание |
|------|-----|-----|----------|
| 31:1 | — | — | Зарезервировано, читается как ноль, изменять нельзя |
| 0 | `RTCIMSC` | RW | 1 — прерывание разрешено, 0 — замаскировано |

## Описание

Бит `RTCIMSC[0]` определяет, попадает ли флаг совпадения на выход
`RTCINTR`. При чтении возвращается текущее значение маски.

Несмотря на название «маска», единица в бите **разрешает** прерывание,
а ноль — маскирует его. Такое соглашение принято в компонентах PrimeCell
и позволяет описывать комбинацию регистров одной формулой:

```text
RTCMIS = RTCRIS AND RTCIMSC
```

## Влияние на флаг

Маска не влияет на сам флаг в `RTCRIS`. Если прерывание замаскировано,
флаг всё равно устанавливается и сохраняется. После снятия маски
необработанное прерывание сработает немедленно — на выходе `RTCINTR`
появится активный уровень.

Это свойство следует учитывать при инициализации: перед разрешением
прерывания полезно сбросить возможный устаревший флаг записью в `RTCICR`.

## Пример использования

```c
#define RTC_IMSC    (RTC_BASE + 0x010)
#define RTC_ICR     (RTC_BASE + 0x01C)

/* Сбросить возможный старый флаг, затем разрешить прерывание */
*(volatile uint32_t *)RTC_ICR  = 1;
*(volatile uint32_t *)RTC_IMSC = 1;
```

## Замечание о задержке

Запись маски пересекает границу тактовых доменов и применяется через
несколько тактов `PCLK`. Немедленное чтение регистра может вернуть ещё
старое значение.
