# 2.1. Обзор

Контроллер PL031 состоит из нескольких функциональных блоков, связанных
между собой двумя тактовыми доменами. Регистры, доступные по шине APB,
тактируются сигналом `PCLK`, а счётчик секунд — сигналом `CLK1HZ`.
Пересечение доменов выполняет блок синхронизации.

Упрощённая структура контроллера показана на рисунке ниже.

```text
                  ┌──────────────────────────────────────────────┐
                  │              PrimeCell RTC (PL031)           │
                  │                                              │
   AMBA APB ─────▶│  ┌────────────┐      ┌───────────────────┐   │
   (PCLK)         │  │  Интерфейс │      │  Блок регистров   │   │
                  │  │    APB     │─────▶│  (PCLK-домен)     │   │
                  │  └────────────┘      └─────────┬─────────┘   │
                  │                                │             │
                  │                      ┌─────────▼─────────┐   │
                  │                      │ Блок синхронизации│   │
                  │                      └────┬─────────┬────┘   │
                  │                           │         │        │
                  │              ┌────────────▼──┐   ┌──▼─────┐  │
   CLK1HZ ───────▶│              │ Блок счётчика │◀──│ Блок   │  │
                  │              └───────┬───────┘   │ обнов- │  │
                  │                      │           │ ления  │  │
                  │              ┌───────▼───────┐   └──┬─────┘  │
```

## Состав блоков

| Блок | Назначение |
|------|------------|
| Интерфейс AMBA APB | Приём и выполнение операций чтения и записи по шине APB |
| Блок регистров | Хранение всех программно-доступных регистров |
| Блок управления | Разрешение работы счётчика и общее управление |
| Блок обновления | Обнаружение совпадения, установка флага прерывания, загрузка счётчика |
| Блок синхронизации | Передача сигналов между доменами `PCLK` и `CLK1HZ` |
| Блок счётчика | 32-битный счётчик секунд |
| Тестовые регистры и логика | Интеграционная тестовая обвязка |

## Два домена тактирования

Разделение на домены — важная особенность контроллера. Шина APB работает
на частоте `PCLK`, которая обычно составляет десятки или сотни мегагерц,
а счётчик продвигается на один шаг в секунду. Запись нового значения
в регистр загрузки должна быть безопасно передана в медленный домен,
а признак совпадения — обратно в быстрый, чтобы программное обеспечение
увидело его при чтении регистра состояния.

Именно поэтому все регистры, содержимое которых должно пересекать границу
доменов (`RTCLR`, `RTCMR`, `RTCCR`, `RTCIMSC`), проходят через блок
синхронизации, а не читаются и не пишутся напрямую из домена `PCLK`.

## Что важно для интегратора

- Сигнал `CLK1HZ` должен быть стабильным: именно его фронт увеличивает
  счётчик.
- Регистр совпадения `RTCMR` сохраняет значение при сбросе шины `PRESETn`
  и сбрасывается только сигналом `nPOR`.
- Выход `RTCINTR` — единственный функциональный выход контроллера; он
  подключается к контроллеру прерываний системы.

Детальное описание каждого блока приведено в разделе 2.2, а порядок работы
контроллера — в разделе 2.3.
