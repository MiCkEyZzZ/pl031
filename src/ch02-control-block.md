# 2.2.3. Блок управления

Блок управления определяет, продвигается ли счётчик. Его единственный
программно-доступный орган управления — бит `RTCEN` в регистре `RTCCR`.

## Принцип работы

Блок формирует внутренний сигнал разрешения счёта. Пока сигнал активен,
каждый фронт `CLK1HZ` увеличивает счётчик на единицу. Когда сигнал снят,
счётчик сохраняет текущее значение, а все остальные функции — чтение
регистра данных, сравнение с регистром совпадения, прерывания — продолжают
работать.

Это важное свойство: остановка счётчика не отключает прерывание. Если
счётчик остановлен в момент, когда его значение уже равно значению
`RTCMR`, флаг прерывания останется установленным до явного сброса через
`RTCICR`.

## Значение после сброса

После сброса `RTCEN = 0`: счётчик остановлен. Программное обеспечение должно
явно установить бит `RTCEN`, чтобы начать отсчёт времени. Такое поведение
защищает от неконтролируемого изменения счётчика до того, как программное
обеспечение загрузит корректное начальное значение.

## Типичная последовательность запуска

1. Записать начальное значение времени в `RTCLR` — счётчик загрузится
   этим значением.
2. При необходимости записать значение будильника в `RTCMR`.
3. Разрешить прерывание, установив бит `RTCIMSC[0] = 1`.
4. Установить `RTCCR[0] = 1`, чтобы разрешить счёт.

Порядок шагов 1 и 4 может быть изменён: загрузка значения в `RTCLR`
не требует, чтобы счётчик был разрешён.

## Взаимодействие с блоком обновления

Блок управления не участвует в сравнении значений и не формирует флаг
прерывания — это задачи блока обновления. Разделение обязанностей позволяет
независимо управлять темпом счёта и обработкой совпадений.
