# ARM PrimeCell Real-Time Clock (PL031) — техническое руководство

Русскоязычная книга об контроллере часов реального времени **ARM PrimeCell
PL031**, собранная на [mdBook](https://rust-lang.github.io/mdBook/).

Структура и технические данные соответствуют официальному руководству ARM
**DDI 0224B** (ARM PrimeCell Real-Time Clock (PL031) Technical Reference
Manual, 2001). Это самостоятельный текст, а не официальный перевод ARM.

## Содержание

| Раздел | О чём |
|--------|-------|
| Предисловие | Назначение, аудитория, соглашения, литература |
| Глава 1 | Назначение и возможности контроллера |
| Глава 2 | Функциональное описание: блоки, APB, сброс, тактирование |
| Глава 3 | Модель программиста: карта и описание всех регистров, прерывания |
| Глава 4 | Тестовая модель: интеграционная обвязка, scan-тестирование |
| Приложение A | Описание сигналов |
| Приложение Б | Глоссарий |

## Сборка

```console
$ cargo install mdbook      # если ещё не установлен
$ mdbook serve --open       # предпросмотр на http://localhost:3000
$ mdbook build              # готовый сайт в ./book
```

```
.
├── book.toml          # конфигурация mdBook
├── src/               # исходники книги (Markdown)
│   ├── SUMMARY.md     # оглавление
│   └── ...

```

Собранный сайт (`book/`) в репозиторий не попадает — он создаётся командой
`mdbook build`.

## Источники

- ARM DDI 0224B, ARM PrimeCell Real-Time Clock (PL031) Technical Reference Manual.
- Драйвер `drivers/rtc/rtc-pl031.c` ядра Linux.
- Модель `hw/rtc/pl031.c` эмулятора QEMU.

## Лицензия и правовая оговорка

Текст книги написан самостоятельно и описывает технические факты устройства.
Документ ARM DDI 0224B является собственностью ARM Limited; его дословный
перевод или воспроизведение здесь не приводится.
