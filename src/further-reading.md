# Дополнительная литература

Для работы с контроллером полезны следующие документы и спецификации.

## Документы ARM

| Документ | О чём |
|----------|-------|
| ARM DDI 0224B | ARM PrimeCell Real-Time Clock (PL031) Technical Reference Manual — оригинал этой книги |
| AMBA Specification (ARM IHI 0011) | Спецификация шины AMBA, включая протокол APB |
| PrimeCell Specification | Общие требования к периферийным компонентам PrimeCell, включая регистры идентификации |
| AMBA APB Protocol Specification | Детальное описание операций чтения и записи APB |

## Стандарты и соглашения

- **JEP106** — соглашение о кодах производителей, используемое в регистрах
  идентификации периферии.
- **IEEE 1149.1 (JTAG)** и **IEEE 1500** — стандарты тестирования цифровых
  блоков, на которые опирается глава 4.

## Программное обеспечение

Контроллер поддерживается открытым ПО, что удобно для проверки поведения
при отсутствии документации под рукой:

- драйвер `drivers/rtc/rtc-pl031.c` в ядре Linux;
- модель `hw/rtc/pl031.c` в эмуляторе QEMU;
- описание привязки к дереву устройств (`arm,pl031`) в документации
  ядра Linux.

Модель QEMU полезна тем, что показывает, как регистры ведут себя при
обращениях, которые аппаратура не поддерживает: например, запись в регистр
только для чтения игнорируется, а чтение регистра только для записи
возвращает неопределённое значение.

## Что читать дальше

После знакомства с PL031 имеет смысл изучить:

- общий протокол APB — чтобы понимать временные диаграммы обмена;
- другие компоненты PrimeCell (контроллер прерываний, таймеры) — их
  регистровая модель устроена похоже;
- подсистему RTC ядра Linux — если предстоит писать или сопровождать драйвер.
