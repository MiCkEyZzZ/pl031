# 2.2.1. Интерфейс AMBA APB

Контроллер подключён к шине AMBA APB как ведомое устройство. Обмен всегда
инициирует ведущий — обычно мост APB, соединяющий быструю шину системы
с медленной периферией.

## Сигналы обмена

| Сигнал | Направление | Назначение |
|--------|-------------|------------|
| `PCLK` | вход | Тактовый сигнал шины |
| `PRESETn` | вход | Сброс шины, активен низким уровнем |
| `PSEL` | вход | Выбор устройства |
| `PENABLE` | вход | Разрешение передачи |
| `PWRITE` | вход | 1 — запись, 0 — чтение |
| `PADDR[11:2]` | вход | Адрес слова внутри блока |
| `PWDATA[31:0]` | вход | Данные для записи |
| `PRDATA[31:0]` | выход | Данные при чтении |

Адрес передаётся битами `PADDR[11:2]`: младшие два бита отбрасываются,
поскольку все регистры выровнены по границе 32-битного слова. Двенадцать
бит адреса покрывают пространство 4 КБ — этого достаточно для регистров
общих, идентификационных и тестовых.

## Цикл записи

Активная фаза передачи начинается, когда ведущий одновременно выставляет
`PSEL` и `PENABLE` при `PWRITE = 1`. В этот момент контроллер принимает
данные `PWDATA` и адрес `PADDR` и выполняет запись в соответствующий регистр.
Данные фиксируются по фронту `PCLK`.

```text
            ┌──┐  ┌──┐  ┌──┐  ┌──┐
PCLK     ───┘  └──┘  └──┘  └──┘  └───
         ┌──────────────────────────┐
PSEL     ┘                          └──
         ┌──────────────────────────┐
PENABLE  ┘                          └──
         ┌──────────────────────────┐
PWRITE   ┘                          └──
         ┌──────────────────────────┐
PADDR    ┘      адрес регистра      └──
         ┌──────────────────────────┐
PWDATA   ┘      данные для записи   └──
                    ▲
                    └── запись происходит здесь
```

## Цикл чтения

При чтении (`PWRITE = 0`) контроллер выставляет значение регистра
на `PRDATA`. Данные действительны в конце активной фазы передачи и снимаются
после деактивации `PENABLE` или `PSEL`.

```text
            ┌──┐  ┌──┐  ┌──┐  ┌──┐
PCLK     ───┘  └──┘  └──┘  └──┘  └───
         ┌──────────────────────────┐
PSEL     ┘                          └──
         ┌──────────────────────────┐
PENABLE  ┘                          └──
         ┌──────────────────────────┐
PRDATA   ─────────┤ значение ├──────
                          ▲
                          └── данные действительны здесь
```

## Особенности интерфейса

- Все регистры доступны только 32-битными словами. Обращения полусловами
  и байтами не поддерживаются.
- Запись в регистр только для чтения игнорируется; чтение регистра только
  для записи возвращает неопределённое значение.
- Тестовые регистры (смещения `0x80`–`0x90`) доступны по той же шине, что
  и обычные, но не должны использоваться в штатном режиме работы.
