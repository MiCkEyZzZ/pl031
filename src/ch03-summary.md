# 3.2. Сводка регистров

В таблице приведены все программно-доступные регистры контроллера.
Смещения указаны относительно базового адреса блока.

| Смещение | Имя | Тип | Ширина | Сброс | Назначение |
|----------|-----|-----|--------|-------|------------|
| `0x000` | `RTCDR` | RO | 32 | — | Текущее значение счётчика |
| `0x004` | `RTCMR` | RW | 32 | `0x00000000` | Значение совпадения (будильник) |
| `0x008` | `RTCLR` | RW | 32 | `0x00000000` | Загрузка счётчика |
| `0x00C` | `RTCCR` | RW | 1 | `0x00000000` | Управление: разрешение счёта |
| `0x010` | `RTCIMSC` | RW | 1 | `0x00000000` | Маска прерывания |
| `0x014` | `RTCRIS` | RO | 1 | `0x00000000` | Сырой статус прерывания |
| `0x018` | `RTCMIS` | RO | 1 | `0x00000000` | Маскированный статус прерывания |
| `0x01C` | `RTCICR` | WO | 1 | `0x00000000` | Сброс прерывания |
| `0x080` | `RTCITCR` | RW | 3 | `0x00000000` | Управление интеграционным тестом |
| `0x084` | `RTCITIP` | RW | 1 | `0x00000000` | Установка входов теста |
| `0x088` | `RTCITOP` | RW | 1 | `0x00000000` | Наблюдение выходов теста |
| `0x08C` | `RTCTOFFSET` | RW | 32 | `0x00000000` | Тестовое смещение |
| `0x090` | `RTCTCOUNT` | RW | 32 | `0x00000000` | Тестовое значение счётчика |
| `0xFE0` | `RTCPeriphID0` | RO | 8 | `0x31` | Идентификация периферии, байт 0 |
| `0xFE4` | `RTCPeriphID1` | RO | 8 | `0x10` | Идентификация периферии, байт 1 |
| `0xFE8` | `RTCPeriphID2` | RO | 8 | `0x14` | Идентификация периферии, байт 2 |
| `0xFEC` | `RTCPeriphID3` | RO | 8 | `0x00` | Идентификация периферии, байт 3 |
| `0xFF0` | `RTCPCellID0` | RO | 8 | `0x0D` | Идентификация PrimeCell, байт 0 |
| `0xFF4` | `RTCPCellID1` | RO | 8 | `0xF0` | Идентификация PrimeCell, байт 1 |
| `0xFF8` | `RTCPCellID2` | RO | 8 | `0x05` | Идентификация PrimeCell, байт 2 |
| `0xFFC` | `RTCPCellID3` | RO | 8 | `0xB1` | Идентификация PrimeCell, байт 3 |

## Пояснения к таблице

**Ширина.** Указана ширина используемой части регистра. Регистры `RTCCR`,
`RTCIMSC`, `RTCRIS`, `RTCMIS` и `RTCICR` занимают одно 32-битное слово,
но содержат единственный значащий бит `[0]`; остальные биты зарезервированы
и читаются как нули.

**Сброс.** Для `RTCDR` значение после сброса не определено: оно зависит
от состояния счётчика. Для `RTCMR` указанное значение действует после
сброса по питанию (`nPOR`); сброс шины `PRESETn` на этот регистр
не влияет.

**Тип.** `WO` означает, что чтение регистра не имеет смысла и возвращает
неопределённое значение. `RO` означает, что запись игнорируется.

## Карта адресов

```text
base + 0x000  RTCDR        ┐
base + 0x004  RTCMR        │
base + 0x008  RTCLR        │ общие регистры
base + 0x00C  RTCCR        │
base + 0x010  RTCIMSC      │
base + 0x014  RTCRIS       │
base + 0x018  RTCMIS       │
base + 0x01C  RTCICR       ┘
base + 0x080  RTCITCR      ┐
base + 0x084  RTCITIP      │ тестовые регистры
base + 0x088  RTCITOP      │
base + 0x08C  RTCTOFFSET   │
base + 0x090  RTCTCOUNT    ┘
base + 0xFE0  RTCPeriphID0 ┐
base + 0xFE4  RTCPeriphID1 │ идентификация периферии
base + 0xFE8  RTCPeriphID2 │
base + 0xFEC  RTCPeriphID3 ┘
base + 0xFF0  RTCPCellID0  ┐
base + 0xFF4  RTCPCellID1  │ идентификация PrimeCell
base + 0xFF8  RTCPCellID2  │
base + 0xFFC  RTCPCellID3  ┘
```
