# 3.3.2. Регистр совпадения RTCMR

`RTCMR` — 32-битный регистр чтения/записи, содержащий значение, при
достижении которого счётчиком формируется прерывание.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x004` |
| Тип | RW |
| Ширина | 32 бита |
| Значение после сброса | `0x00000000` (по `nPOR`) |

## Битовые поля

| Биты | Имя | Тип | Описание |
|------|-----|-----|----------|
| 31:0 | `RTCMR` | RW | Значение совпадения |

## Описание

Когда значение счётчика становится равным значению `RTCMR`, блок обновления
устанавливает флаг `RTCRIS[0]`. Если прерывание разрешено, на выходе
`RTCINTR` появляется запрос.

Сравнение выполняется на каждом шаге счёта, то есть с частотой 1 Гц.
Совпадение возможно только один раз за полный оборот счётчика, поэтому
после срабатывания программное обеспечение должно записать новое значение,
если требуется повторное срабатывание.

## Сохранение при сбросе шины

`RTCMR` не сбрасывается сигналом `PRESETn`. Значение сохраняется при
перезапуске шины и сбрасывается только сигналом `nPOR` (сброс по включению
питания). Это позволяет сохранить настройку будильника, если сброс шины
не означает потерю питания.

## Пример использования

```c
/* Запрограммировать срабатывание через 60 секунд */
uint32_t now = *(volatile uint32_t *)(RTC_BASE + 0x000);
*(volatile uint32_t *)(RTC_BASE + 0x004) = now + 60;

/* Разрешить прерывание по совпадению */
*(volatile uint32_t *)(RTC_BASE + 0x010) |= 1;
```

## Замечание о точном моменте

Запись в `RTCMR` проходит через блок синхронизации. Если новое значение
равно текущему значению счётчика, флаг может установиться в ближайшем такте
`CLK1HZ` либо не установиться вовсе — в зависимости от того, успела ли
запись примениться до момента сравнения. Для надёжного срабатывания
следует программировать значение, отличное от текущего.
