# 2.2.6. Блок счётчика

Счётчик — центральный элемент контроллера. Он представляет собой 32-битный
регистр, который увеличивается на единицу по каждому фронту сигнала
`CLK1HZ`, если счёт разрешён.

## Разрядность и переполнение

Счётчик хранит значение от `0x00000000` до `0xFFFFFFFF`. При достижении
максимума следующий шаг переводит его в ноль — переполнение происходит
естественным образом, без отдельного флага.

При частоте 1 Гц полный оборот счётчика занимает

```text
2^32 секунд ≈ 4 294 967 296 с ≈ 136,1 года
```

Такого диапазона достаточно для абсолютного времени в секундах, отсчитанного
от произвольной эпохи.

## Чтение

Текущее значение доступно через регистр `RTCDR`. Чтение возвращает значение,
зафиксированное на момент обращения. Поскольку счётчик принадлежит домену
`CLK1HZ`, а шина — домену `PCLK`, значение проходит через блок
синхронизации, и прочитанное число может отставать от реального на несколько
тактов.

Для практических задач это отставание несущественно: оно измеряется
наносекундами при типичных частотах `PCLK`.

## Загрузка

Запись в `RTCLR` заменяет текущее значение счётчика. Счёт после загрузки
продолжается с нового значения; счётчик не останавливается и не начинает
отсчёт заново с нуля.

Загрузку удобно использовать для установки календарного времени: программное
обеспечение вычисляет количество секунд от выбранной эпохи и записывает
его в `RTCLR`.

## Остановка

Если бит `RTCCR[0]` равен нулю, счётчик не изменяется. При этом чтение
`RTCDR` возвращает последнее значение, а сравнение с `RTCMR` продолжает
выполняться. Это позволяет использовать контроллер как «замороженные»
часы, например при отладке.
