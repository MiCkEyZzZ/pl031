# 3.4. Регистры идентификации периферии RTCPeriphID0-3

Четыре 8-битных регистра в диапазоне смещений `0xFE0`–`0xFEC` содержат
постоянную информацию о компоненте. Вместе они образуют 32-битный
идентификатор периферии.

## Расположение

| Регистр | Смещение | Значение |
|---------|----------|----------|
| `RTCPeriphID0` | `0xFE0` | `0x31` |
| `RTCPeriphID1` | `0xFE4` | `0x10` |
| `RTCPeriphID2` | `0xFE8` | `0x14` |
| `RTCPeriphID3` | `0xFEC` | `0x00` |

32-битное слово, образованное этими регистрами (от младшего байта
к старшему), равно `0x00141031`.

## Назначение

Регистры позволяют программному обеспечению убедиться, что по указанному
адресу находится именно контроллер PL031, а не другое устройство. Это
полезно при автоматическом обнаружении периферии и при проверке
совместимости.

Регистры жёстко заданы в кремнии: запись в них не изменяет значение.

## Поля идентификатора

| Поле | Смысл | Значение для PL031 |
|------|-------|--------------------|
| PartNumber | Номер компонента в семействе PrimeCell | PL031 |
| Designer | Код производителя | ARM |
| Revision | Номер ревизии компонента | 1 |
| Configuration | Конфигурация блока | `0x00` |

В регистре `RTCPeriphID3` значащими являются биты `[7:0]`; они содержат
поле `Configuration` и читаются как `0x00`. Биты `[15:8]` зарезервированы.

В регистре `RTCPeriphID2` биты `[7:4]` содержат номер ревизии, а биты
`[3:0]` — старшую часть кода производителя; для ARM они читаются
как `0x4`.

## Пример проверки

```c
#define RTC_PERIPHID0 (RTC_BASE + 0xFE0)

static int pl031_present(void)
{
    uint32_t id0 = *(volatile uint32_t *)RTC_PERIPHID0;
    return (id0 & 0xFF) == 0x31;
}
```

Проверка только одного байта достаточна, если адрес блока уже известен
из описания платформы. Для полной идентификации следует прочитать все
четыре регистра и сравнить составное значение с `0x00141031`.

## Замечание

Разрядность регистров — 8 бит, но расположены они в 32-битных словах,
поэтому при чтении старшие байты слова содержат неопределённые значения.
При сравнении следует маскировать младший байт.
