# 3.1. Общие сведения

Контроллер предоставляет набор 32-битных регистров, отображённых
в адресное пространство системы. Базовый адрес блока назначается при
интеграции; все смещения в этой главе указаны относительно него.

## Правила доступа

- Все обращения выполняются 32-битными словами и выровнены по границе
  слова.
- Адрес регистра складывается из базового адреса блока и смещения:
  `адрес = base + offset`.
- Регистры, помеченные как RO, доступны только для чтения.
- Регистры, помеченные как WO, доступны только для записи.
- Запись в зарезервированные поля запрещена (DNM). При записи в регистр
  зарезервированные биты должны сохранять прочитанное значение.
- Чтение неиспользуемых битов возвращает ноль, если не указано иное.

## Группы регистров

| Диапазон смещений | Группа |
|-------------------|--------|
| `0x000`–`0x01C` | Общие регистры |
| `0x080`–`0x090` | Тестовые регистры (глава 4) |
| `0xFE0`–`0xFEC` | Регистры идентификации периферии |
| `0xFF0`–`0xFFC` | Регистры идентификации PrimeCell |

## Сброс регистров

Большинство регистров сбрасываются сигналом `PRESETn`. Исключение
составляют `RTCMR`, `RTCTOFFSET` и `RTCTCOUNT`: они сохраняют значение
при сбросе шины и сбрасываются только сигналом `nPOR`. В таблицах этой
главы такие регистры отмечены отдельно.

## Соглашение об именах

Регистры имеют префикс `RTC`. Суффиксы образованы от английских названий:

| Суффикс | Значение |
|---------|----------|
| `DR` | Data Register — регистр данных |
| `MR` | Match Register — регистр совпадения |
| `LR` | Load Register — регистр загрузки |
| `CR` | Control Register — регистр управления |
| `IMSC` | Interrupt Mask Set/Clear — маска прерывания |
| `RIS` | Raw Interrupt Status — сырой статус прерывания |
| `MIS` | Masked Interrupt Status — маскированный статус |
| `ICR` | Interrupt Clear — сброс прерывания |
