# 3.3.3. Регистр загрузки RTCLR

`RTCLR` — 32-битный регистр, запись в который загружает счётчик новым
значением.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x008` |
| Тип | RW |
| Ширина | 32 бита |
| Значение после сброса | `0x00000000` |

## Битовые поля

| Биты | Имя | Тип | Описание |
|------|-----|-----|----------|
| 31:0 | `RTCLR` | RW | Значение, загружаемое в счётчик |

## Описание

Запись в `RTCLR` передаёт новое значение в блок обновления, после чего
счётчик принимает его и продолжает счёт с этого значения. Регистр не
останавливает счётчик и не сбрасывает флаг прерывания.

Чтение возвращает последнее записанное значение. Оно не обязано совпадать
с текущим значением счётчика: для чтения текущего времени используется
`RTCDR`.

## Применение

`RTCLR` — единственный способ изменить показания счётчика. Типичный сценарий
установки календарного времени:

```c
/* Установить время: секунды от выбранной эпохи */
uint64_t seconds = ...;
*(volatile uint32_t *)(RTC_BASE + 0x008) = (uint32_t)seconds;
```

## Задержка применения

Между записью и фактической загрузкой значения проходит несколько тактов
`CLK1HZ` — значение пересекает границу тактовых доменов. При частоте 1 Гц
задержка может достигать одной секунды. Если приложению нужна точность
до секунды, значение следует загружать заранее либо компенсировать задержку.

## Взаимодействие со счётчиком

Если счётчик остановлен (`RTCCR[0] = 0`), запись в `RTCLR` всё равно
загружает новое значение. Счёт начнётся с этого значения после того, как
бит `RTCEN` будет установлен.
