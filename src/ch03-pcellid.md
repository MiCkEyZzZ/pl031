# 3.5. Регистры идентификации PrimeCell RTCPCellID0-3

Четыре 8-битных регистра в диапазоне смещений `0xFF0`–`0xFFC` образуют
стандартный идентификатор PrimeCell — общий для всех компонентов этого
семейства.

## Расположение

| Регистр | Смещение | Значение |
|---------|----------|----------|
| `RTCPCellID0` | `0xFF0` | `0x0D` |
| `RTCPCellID1` | `0xFF4` | `0xF0` |
| `RTCPCellID2` | `0xFF8` | `0x05` |
| `RTCPCellID3` | `0xFFC` | `0xB1` |

Составное 32-битное значение равно `0xB105F00D`.

## Назначение

Идентификатор PrimeCell позволяет программному обеспечению отличить
компоненты этого семейства от периферии других производителей
или архитектур. Значение `0xB105F00D` закреплено за семейством PrimeCell.

В отличие от `RTCPeriphID0-3`, которые указывают на конкретный компонент
(PL031), регистры `RTCPCellID0-3` указывают на семейство в целом.

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 7:0 | `RTCPCellID0` | Читается как `0x0D` |
| 7:0 | `RTCPCellID1` | Читается как `0xF0` |
| 7:0 | `RTCPCellID2` | Читается как `0x05` |
| 7:0 | `RTCPCellID3` | Читается как `0xB1` |

Биты `[15:8]` каждого регистра зарезервированы: читаются как неопределённое
значение и должны считаться нулями.

## Пример проверки

```c
static uint8_t pcell_id_byte(int i)
{
    return *(volatile uint32_t *)(RTC_BASE + 0xFF0 + 4 * i) & 0xFF;
}

static int is_primecell(void)
{
    return pcell_id_byte(0) == 0x0D &&
           pcell_id_byte(1) == 0xF0 &&
           pcell_id_byte(2) == 0x05 &&
           pcell_id_byte(3) == 0xB1;
}
```

## Замечание

Регистры только для чтения. Запись игнорируется. Поскольку регистры
8-битные, при чтении 32-битного слова старшие байты содержат
неопределённые значения — сравнивать нужно только младший байт.
