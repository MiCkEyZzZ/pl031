# 3.3.1. Регистр данных RTCDR

`RTCDR` — 32-битный регистр только для чтения, содержащий текущее значение
счётчика секунд.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x000` |
| Тип | RO |
| Ширина | 32 бита |
| Значение после сброса | Не определено |

## Битовые поля

| Биты | Имя | Тип | Описание |
|------|-----|-----|----------|
| 31:0 | `RTCDR` | RO | Текущее значение счётчика |

## Описание

Чтение `RTCDR` возвращает значение, которое счётчик имел на момент
обращения. Значение передаётся из домена `CLK1HZ` в домен `PCLK` через
блок синхронизации, поэтому оно может отставать от истинного на несколько
тактов `PCLK`.

Регистр доступен как в штатном режиме, так и при остановленном счётчике.
В последнем случае чтение возвращает последнее значение, которое счётчик
принял до остановки.

## Запись

Запись в `RTCDR` игнорируется. Для изменения значения счётчика используется
регистр `RTCLR` (см. раздел 3.3.3).

## Пример использования

```c
/* Прочитать текущее время в секундах */
uint32_t now = *(volatile uint32_t *)(RTC_BASE + 0x000);
```

Поскольку счётчик 32-битный, значение переполняется примерно раз в 136 лет.
При вычислении разницы между двумя показаниями переполнение можно
не учитывать, если интервал заведомо меньше периода оборота: разность
беззнаковых 32-битных чисел даёт корректный результат и при переходе через
ноль.
