# ARM PrimeCell Real-Time Clock (PL031)

## Техническое руководство

Контроллер часов реального времени ARM PrimeCell PL031 — это периферийное
устройство на шине AMBA APB, которое ведёт счёт секунд в 32-битном счётчике
и вырабатывает прерывание при совпадении показаний счётчика с программируемым
значением.

Эта книга — русскоязычное описание устройства, составленное по структуре
официального технического руководства ARM **DDI 0224B** (ARM PrimeCell
Real-Time Clock (PL031) Technical Reference Manual, 2001). Она не является
официальным переводом ARM и не заменяет оригинальную документацию.

### Как собрать

```console
$ mdbook build      # результат в ./book
$ mdbook serve      # предпросмотр на http://localhost:3000
```

Книга собирается статически: `mdbook build` создаёт каталог `book/`, который
можно открыть локально или опубликовать на любом статическом хостинге.

### Соглашение об обозначениях

Регистры записываются прописными буквами с префиксом `RTC` (`RTCDR`, `RTCMR`,
`RTCIMSC` и т. д.). Смещения регистров указаны относительно базового адреса
блока, который назначается при интеграции контроллера в систему на кристалле.
