# 4.1. Обзор тестовой обвязки

Помимо штатной логики, контроллер содержит интеграционную тестовую обвязку
(integration test harness). Она позволяет инженеру, работающему с готовым
кристаллом, управлять внутренними сигналами блоков и наблюдать их состояние
через обычные регистры APB — без доступа к внутренним цепям.

## Задачи тестовой обвязки

- Проверить, что блоки контроллера правильно соединены между собой
  на уровне интеграции.
- Наблюдать внутренние сигналы, недоступные через штатные регистры.
- Ускорить проверку медленных цепей: счётчик, тактируемый 1 Гц, иначе
  пришлось бы ждать секунды между шагами.

## Структура

```text
        APB (PCLK)                        CLK1HZ
   ┌───────────────────┐          ┌───────────────────┐
   │  RTCITCR  (0x080) │          │                   │
   │  RTCITIP  (0x084) │─────────▶│  Внутренние блоки │
   │  RTCITOP  (0x088) │◀─────────│    контроллера    │
   │  RTCTOFFSET(0x08C)│          │                   │
   │  RTCTCOUNT(0x090) │          │                   │
   └───────────────────┘          └───────────────────┘
```

Регистры `RTCITCR`, `RTCITIP` и `RTCITOP` управляют тестовым режимом
и передают значения сигналов. Регистры `RTCTOFFSET` и `RTCTCOUNT` дают
прямой доступ к счётчику и его смещению, что позволяет проверять логику
сравнения, не дожидаясь реального хода времени.

## Ограничения

- Тестовая обвязка не предназначена для работы в штатном режиме.
  Обращение к тестовым регистрам во время нормальной работы нарушает
  функционирование контроллера.
- Не все сигналы можно протестировать через обвязку. Сигналы сброса
  и тактирования проверяются иначе (см. раздел 4.6).
- Точное назначение отдельных битов тестовых регистров определяется
  реализацией тестовой обвязки; ниже описаны назначение регистров
  и правила доступа к ним.

## Порядок использования

1. Перевести контроллер в тестовый режим через `RTCITCR`.
2. При необходимости задать значения через `RTCITIP` или `RTCTCOUNT`.
3. Прочитать результат через `RTCITOP` или `RTCTCOUNT`.
4. Вывести контроллер из тестового режима и выполнить сброс.

Выполнять эти действия следует только на стенде или в составе
производственного теста.
