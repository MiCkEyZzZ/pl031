# Приложение Б. Глоссарий

**AMBA** (Advanced Microcontroller Bus Architecture) — семейство шин
и протоколов, разработанных ARM для соединения блоков внутри системы
на кристалле.

**APB** (Advanced Peripheral Bus) — простая шина в составе AMBA,
предназначенная для медленной периферии. Характеризуется низким
энергопотреблением и простотой протокола; обмен выполняется за две фазы.

**ATPG** (Automatic Test Pattern Generation) — автоматическая генерация
тестовых воздействий для проверки цифровых схем.

**DNM** (Do Not Modify) — пометка зарезервированного поля регистра:
значение поля нельзя изменять при записи.

**IMSC** (Interrupt Mask Set/Clear) — регистр маски прерывания. В компонентах
PrimeCell единица в бите разрешает прерывание, ноль — маскирует.

**ISR** (Interrupt Service Routine) — подпрограмма обработки прерывания.

**JEP106** — стандарт, описывающий коды производителей интегральных схем;
используется в регистрах идентификации периферии.

**PCLK** — тактовый сигнал шины APB.

**PrimeCell** — семейство готовых периферийных блоков ARM, предназначенных
для интеграции в систему на кристалле. Компоненты PrimeCell имеют
стандартные регистры идентификации.

**RTC** (Real-Time Clock) — часы реального времени: устройство, отсчитывающее
время независимо от работы процессора.

**Scan-тестирование** — метод производственного тестирования, при котором
внутренние триггеры схемы соединяются в цепочки, позволяющие сдвигать
в них произвольные значения.

**SoC** (System on Chip) — система на кристалле: интегральная схема,
объединяющая процессор, память и периферию.

**Будильник** — в контексте этой книги: механизм сравнения значения счётчика
с регистром `RTCMR`, вырабатывающий прерывание при совпадении.

**Домен тактирования** — часть схемы, работающая от одного тактового сигнала.
Контроллер использует два домена: `PCLK` и `CLK1HZ`.

**Маска прерывания** — механизм, позволяющий запретить выдачу прерывания,
не сбрасывая при этом флаг события.

**Переполнение** — переход счётчика из максимального значения в ноль.
Для 32-битного счётчика происходит раз в 2³² шагов.

**Регистр** — адресуемая ячейка хранения внутри периферийного устройства.

**Сброс** — приведение устройства в исходное состояние. В контроллере
различаются сброс шины (`PRESETn`), сброс ядра (`nRTCRST`) и сброс
по питанию (`nPOR`).

**Сырой статус** — состояние флага прерывания до применения маски.

**Эпоха** — начальная точка отсчёта времени. Контроллер хранит просто число
секунд; выбор эпохи (например, 1 января 1970 года) — задача программного
обеспечения.
